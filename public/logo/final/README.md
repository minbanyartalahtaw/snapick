# Snapick logo — usage guide

**Idea:** the dot of the *i* is a single fresh petal — the one thing you picked.
Rounded lowercase type keeps it soft and friendly; the petal is the only ornament.

## Logo parts

| Part | File | Use |
|---|---|---|
| Wordmark (primary) | `svg/snapick-wordmark.svg` | Headers, packaging, anywhere with room |
| Symbol (s + petal) | `svg/snapick-symbol.svg` | Avatars, small spaces, patterns |
| Symbol, small cut | `svg/snapick-symbol-small.svg` | Below 32 px: larger petal |
| App icon | `svg/snapick-app-icon.svg` | PWA / store icon (rounded tile) |
| Favicon | `web/favicon.ico`, `web/icon.svg` | Browser tab |

## Colour

| Name | HEX | RGB | Role |
|---|---|---|---|
| Snapick Crimson | `#C70036` | 199 0 54 | Petal, app-icon tile, accents |
| Ink | `#2A1F24` | 42 31 36 | Wordmark and symbol letters |
| Blush | `#FFC2D0` | 255 194 208 | Petal on crimson tiles only |
| Rose | `#FF7A98` | 255 122 152 | Petal on dark backgrounds |

## Versions

- **Full colour** — Ink letters + Crimson petal, on white or light backgrounds.
- **Reversed** (`-reversed`) — white letters + Rose petal, on dark backgrounds.
- **One colour** (`-black`, `-white`, `-crimson`) — print, engraving, embroidery, single-colour jobs.

## Clear space & minimum size

- Clear space on every side = the height of the petal.
- Wordmark: minimum 64 px wide on screen, 18 mm in print.
- Symbol: minimum 16 px (use the small cut below 32 px).

## Typeface

Letterforms are outlined from **Quicksand Bold** (SIL Open Font License, free for logos).
Use Quicksand or Inter for supporting text; never retype the logo — use the files.

## Don't

- Change the petal shape, angle (35°) or colour pairing.
- Put the Crimson petal on a Crimson background (use Blush or white).
- Stretch, outline, add shadows/gradients, or recolour the letters crimson with an ink petal.
- Add a second ornament (hearts, sparkles) next to the logo.
